# Derrick Bediako — One-page portfolio

A static, responsive one-page portfolio with:
- smooth scrolling
- scroll-in reveal animations
- stronger glassmorphism panels with transparency and blur
- click/tap-to-reveal project, focus and experience details
- responsive mobile layout
- no framework or build step

## Before publishing
Open `script.js` and replace:
- `email`
- `linkedin`
- `cv`

## Publish
Upload the entire folder to any static host such as GitHub Pages, Netlify, Vercel, or Cloudflare Pages. The site is ready as plain HTML/CSS/JS.
